# Maison Barra - Data terminal

Showcase website of Maison Barra - Data terminal, a Windows desktop application: about 870 stocks with their fundamentals, analyst consensus and links to their latest official reports (10-K, 20-F), plus news, rates, currencies, bonds, crypto and the market regime, in English and French.

Site: https://maximebarraprojects.github.io/stock-selection/
