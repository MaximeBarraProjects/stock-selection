# Maison Barra - Data terminal

Showcase website of Maison Barra - Data terminal, a free Windows desktop application: about 870 stocks with their fundamentals, analyst consensus and links to their latest official reports (10-K, 20-F), plus news, rates, currencies, bonds, crypto and the market regime, in English and French.

Site: https://rayzz73.github.io/stock-selection/

Download: https://github.com/rayzz73/stock-selection/releases/latest (zip of the Windows executable, without any personal data).
